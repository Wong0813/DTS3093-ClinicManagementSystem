# Clinic Management System

Project for DTS3093 Object Oriented Programming.

## Project Description
A Java desktop application that implements a simple clinic management system using Object-Oriented Programming (OOP) concepts such as inheritance, polymorphism, and encapsulation, along with Java Swing GUI dialogs (`JOptionPane`).

## Features
- Patient registration and verification with local file storage (`users.txt`)
- Medical treatment selection (Fever, Cold, Cough) and medicine prescription
- Payment computation and formatted receipt generation

## Files Included
- `ClinicService.java`: Java source code
- `users.txt`: User records
- `report.pdf`: Full project documentation and report

## How to Run
```bash
javac ClinicService.java
java ClinicService
```
